# 赌徒人生 · Godot 工程

M1 垂直切片的骨架。目标只有一个：**验证"网页版的机台能不能搬进 3D 桌面的显示器里"**。

这个骨架全部用灰模占位，没有任何美术资产也能直接跑起来。

> ⚠️ 这份工程是在没有 Godot 的环境里写的，**没有经过实际运行验证**。
> 打开后第一个报错的地方告诉我，我来修。

## 需要你准备的

| | 说明 |
|---|---|
| **Godot 4.3+** | 从 godotengine.org 下载。**标准版即可**，不需要 .NET 版（这里没用 C#） |
| **一个中文字体** | 必须做，否则界面上的中文全是方框 —— Godot 自带字体不含 CJK |
| 美术资产 | 暂时不需要。灰模跑通之后再换 |

### 中文字体怎么加

1. 拿一个思源黑体 / Noto Sans SC 的 `.ttf` 或 `.otf`，丢进 `godot/fonts/`
2. 项目 → 项目设置 → 通用 → GUI → Theme → **Custom Font**，指向那个文件
3. 字体文件的导入设置里勾上 **Multichannel Signed Distance Field**，小字号才不糊

## 跑起来

```
用 Godot 打开 godot/project.godot  →  F5
```

应该看到：一张桌子、一台 CRT 显示器，屏幕里是弹珠机，**鼠标能直接点屏幕里的红色按钮投球**。

### 跑规则测试

```sh
godot --headless --script res://tests/test_plinko_rules.gd
```

验的是赔付表左右对称、由边缘向中间单调不增、返还率落在 0.74 附近、结算永远是整数、同种子可复现 —— 和网页版 `tests/mechanical.test.mjs` 同一批断言。

## 按这个顺序验证

一次只验一件事，坏了才知道是哪儿坏的：

1. **工程能打开吗** —— 打不开就是 `project.godot` 或某个 `.gd` 有语法错
2. **规则测试过吗** —— 过了说明纯逻辑层移植没问题，这是最不容易错的一层
3. **屏幕上有画面吗** —— 有画面说明 SubViewport → 材质这条链通了
4. **点屏幕有反应吗** —— 有反应说明射线拾取 → UV → 视口坐标的换算对了
5. **画面好看吗** —— 到这一步才谈灯光和美术

第 3、4 步是整个方案的技术核心。这两步过了，剩下三台机台就是重复劳动。

## 目录

```
godot/
├── project.godot              # Forward+ 渲染、Wallet 自动加载
├── scenes/
│   ├── main.tscn              # 主场景（只有一个节点，其余由脚本搭）
│   └── ui/plinko_ui.tscn      # 弹珠机界面
├── scripts/
│   ├── main.gd                # 搭桌子、灯光、相机、显示器
│   ├── crt_screen.gd          # ★ SubViewport → 3D 屏幕 + 鼠标事件转发
│   ├── wallet.gd              # 跨机台共享钱包（autoload）
│   ├── rules/plinko_rules.gd  # ★ 从 rules.mjs 移植的纯规则
│   └── ui/plinko_ui.gd        # 界面：只画和收按键，不含规则
└── tests/test_plinko_rules.gd
```

**分层和网页版一致**：`rules/` 是纯逻辑（无节点、可测试），`ui/` 只负责画和收输入，
`crt_screen.gd` 负责把界面送上屏。新增机台就照这个结构加一份。

## 为什么场景是代码搭的

`main.tscn` 里只有一个节点，桌子、灯光、相机全在 `main.gd` 里建。

原因是手写 `.tscn` 容易在节点路径和资源 ID 上出错，而且不好读。等你在编辑器里
调顺了，随时可以把节点拖成真正的场景文件 —— 代码里的数值就是现成的参考值。

## 画面怎么变好看

粗糙感几乎不来自引擎，按影响排序：

**① 灯光和后处理**（最大头）。全在 `main.gd` 的 `_build_environment()` 和
`_build_lights()`：暖台灯配冷环境光的**色温对比**、SSAO 接触阴影、SSIL 让屏幕
的光染到桌面、ACES 色调映射、轻微景深。默认场景和参考图的差距主要就在这儿。

**② 美术方向**。一致性比精度重要 —— 全低模配手绘贴图很好看，低模配 4K PBR 很难看。

**③ 材质**。粗糙度贴图比模型面数重要得多。塑料电话要有磨损，金属要有指纹。

换模型时把对应的 `MeshInstance3D` 换成导入的 `.glb` 即可，灯光和相机不用动。
