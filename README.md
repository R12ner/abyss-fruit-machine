# 深渊水果机 · ABYSS ARCADE

暗黑像素风 24 格八门水果机，只使用模拟 USD，不支持充值、提现或兑换。

在线游戏：https://abyss-fruit-arcade.omiku-9996.chatgpt.site

## 运行

在项目根目录运行 `python3 -m http.server 8000 --directory dist`，然后打开 http://localhost:8000 。无需安装前端依赖。

## 验证

```sh
node tests/game.test.cjs
node tests/bonus.test.cjs
node tests/triples-jackpot.test.cjs
node tests/coin-wallet.test.cjs
```

## 操作界面

机台使用圆形按钮，用途刻在按钮旁；声音按钮带雕刻喇叭图标；问号打开教程，教程按按钮颜色和位置说明用途。水果按钮仅显示图案，倍率与押分位于按钮外。所有控件保留屏幕阅读器名称及键盘焦点。中奖时中央出现按奖项区分的彩灯、奖名和实际得分；支持系统减少动态效果设置。

## 玩法

初始钱包 100 USD 模拟币、机内余额 0 USD，先投币再下注；8 门押注，筹码 1/5/10，单门上限 99。Shift + 点击、右键或减注模式减注。每个主灯落点概率为 1/24，按对应押分和倍率结算。

本版扩展参数（并非所有实体机的统一规则）：每局独立抽取幸运灯奖励：送灯、火车各 1/24，大三元、小三元各 1/60，累积彩金 1/120；五种互斥，总触发概率 1/8。送灯抽 3 个不重复格；火车从随机车头开始顺时针连续亮 4 格。各格按同局押注结算，叠加主灯得分，不额外扣分，不递归触发。

大三元为双七 ×40、星星 ×30、西瓜 ×20；小三元为铃铛 ×20、木瓜 ×15、橙子 ×10。按三个图案的各自押分结算并累加，每门仅一次，未押的门无奖励；与主灯奖励叠加。

彩金池为当前页面独立娱乐积分，初始 1000。成功开始主游戏时系统额外向池中加入 floor(总押/10) 分，不额外扣玩家积分。触发彩金获当前整池（含本局新增额），与主灯奖励相加，池额重置为 1000；不要求押 BAR。比倍不增池额，页面刷新会重置池额和玩家积分，不共享、不持久化。

中奖后可收分或用本轮得分猜大小：小为 1–7，大为 8–14；猜中双倍，猜错比倍分归零。每个主游戏回合最多 5 次，第 5 次猜中自动收分。没有控奖、保底或真实资金。

完整赔率、盘面和结算细节见游戏内「规则说明」。原有水果素材与像素画风保持不变。

投币口左侧有 20 格放币槽。选择 ×1/×5/×10 面值，点击第 N 个位置会放入 N 枚币（按从左到右、从上到下编号）。放币只将钱包金额移到槽内；点击更前位置可减少数量，× 清空并退回钱包。点击投币口一次投入槽内所有币。换单位不改变已摆好的币，重新选位置才按新单位重排。

清空押注后按退币，机内余额进入出币槽，新绘制的立体金属币下落、弹跳后留在槽内。点击槽内领取后才回到钱包。大额出币用代表性的币堆展示，以槽内 USD 数字为准。所有资金转移均在钱包、放币槽、机台和待领取出币槽之间守恒，不连接真实美元或 USDT 交易。

新币使用 image_gen 绘制：绿色金属币面、磨损黄铜厚边、凸起 $、三分之四视角与透明背景。游戏内使用原始透明 PNG，并通过动画完成落币和叠币。
