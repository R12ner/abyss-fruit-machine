# 深渊水果机 · ABYSS ARCADE

暗黑像素风 24 格八门水果机，只使用娱乐积分，不支持充值、提现或兑换。

在线游戏：https://abyss-fruit-arcade.omiku-9996.chatgpt.site

## 运行

在项目根目录运行 `python3 -m http.server 8000 --directory dist`，然后打开 http://localhost:8000 。无需安装前端依赖。

## 验证

```sh
node tests/game.test.cjs
node tests/bonus.test.cjs
```

## 玩法

初始 1000 积分；8 门押注，筹码 1/5/10，单门上限 99。Shift + 点击、右键或减注模式减注。每个主灯落点概率为 1/24，按对应押分和倍率结算。

本版扩展参数（并非所有实体机的统一规则）：每局独立以 1/12 概率触发幸运灯，触发后送灯和火车各占 1/2。送灯抽 3 个不重复格；火车从随机车头开始顺时针连续亮 4 格。各格按同局押注结算，叠加主灯得分，不额外扣分，不递归触发。

中奖后可收分或用本轮得分猜大小：小为 1–7，大为 8–14；猜中双倍，猜错比倍分归零。每个主游戏回合最多 5 次，第 5 次猜中自动收分。没有控奖、保底或真实资金。

完整赔率、盘面和结算细节见游戏内「规则说明」。原有水果素材与像素画风保持不变。
